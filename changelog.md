### Fixed

- Controllers: the game no longer crashes soon after reaching the town with a controller connected and Steam Input on (#47).
- HP bars: the bars of mobs and players no longer all show empty at times (#50).
- Cursor: the game now shows its own mouse cursor, as the official game does, instead of the system one (#54).
- HUD: its texts and outlines are no longer blurry (#55).
- Chat bar: the grey block next to the Chat button is gone (#32).
- Windows: loading a dungeon, and the assets that load during a run (a player joining, a new room), no longer freeze the game for up to several seconds (#48, #49).
